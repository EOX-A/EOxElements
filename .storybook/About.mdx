## Introduction

EOxElements are a set of reusable, modular and highly configurable components for building geospatial applications.
The goal is to reduce code duplication during development, and offer ready-made solutions for quick bootstrapping and
increased long-term stabilty.

## Technology

The EOxElements are a suite of custom elements (a.k.a. [web components](https://www.webcomponents.org/introduction)), which are framework-agnostic.
Thus, they can be used in applications built with Vanilla JavaScript, Vue.js, React, Angular etc. For usage examples please have a look at [the provided examples](/docs/usage--docs).

## Jupyter Wrapper

Additionally to being usable in JavaScript, there is also a wrapper for Jupyter notebooks, called [EOxElements-Jupyter](https://github.com/EOX-A/EOxElements-Jupyter).

## Model Context Protocol (MCP) Server

For usage with AI coding agents, EOxElements provides a server that exposes a set of tools via the Model Context Protocol. For more information, see the [MCP documentation](/docs/mcp--docs).

## Analytics

All human interactions except for pointer and mouse move related events on the EOxElements are recorded using a **eox:activity** `bubbles: true` event. It is then a responsibility of integrating app to listen on the document to pass through a whitelisted selection or all events to the analytics system of their choice.
