# Coding Agents

EOxElements provides several resources to help AI coding agents understand and work with the library.

## LLMs.txt

We provide structured documentation files specifically designed for Large Language Models (LLMs). These files contain comprehensive information about the library, making it easy for AI tools to understand and assist with EOxElements development.

Available routes:

- [`/llms.txt`](./llms.txt) - Contains a structured overview of all documentation pages and their links.
- [`/llms-full.txt`](./llms-full.txt) - Provides comprehensive documentation including getting started guides, API references, and usage examples (snippets).

## MCP Server

The EOxElements MCP Server provides a set of tools for a coding agent to get information about the EOxElements custom elements. It uses the [@modelcontextprotocol/sdk](https://github.com/modelcontextprotocol/typescript-sdk) to expose the tools.

### Hosted

To use the MCP server without installing anything locally, you can point your coding agent to our hosted endpoint:

`https://elements.mcp.eox.at`

### Install

#### NPX

You can use npx to run the mcp-server:

```bash
npx @eox/elements-mcp-server
```

#### Global Install

Install the package globally from npm:

```bash
npm install -g @eox/elements-mcp-server
```

Then, run the server:

```bash
eox-elements-mcp-server
```

### Getting Started

Every agentic AI software is different, but usually some config file needs to be set up to define the available MCP servers.
The `@eox/elements-mcp-server` will start on `http://localhost:3000` (hosted: `https://elements.mcp.eox.at`) and a compatible coding agent will be able to discover and use the tools from that endpoint.

### Available Tools

The following tools are available:

- `list_elements`: List all available EOxElements custom elements.
- `get_element_details`: Get the full details for a specific EOxElements custom element.
- `get_element_stories`: Get the stories (examples/snippets) for a specific EOxElements custom element (includes `_meta.ui.resourceUri` pointing to `ui://eox-elements/preview` for MCP Apps hosts).
- `get_element_attributes`: Get the attributes for a specific EOxElements custom element.
- `get_element_properties`: Get the properties for a specific EOxElements custom element.
- `get_element_events`: Get the events for a specific EOxElements custom element.
- `get_element_methods`: Get the methods for a specific EOxElements custom element.
- `get_element_slots`: Get the slots for a specific EOxElements custom element.
- `get_element_css_properties`: Get the CSS custom properties for a specific EOxElements custom element.
- `get_element_css_parts`: Get the CSS shadow parts for a specific EOxElements custom element.

## A2UI Integration

EOxElements is compatible with [**A2UI** (Agent-to-User Interface)](https://a2ui.org/) via our `@eox/elements-a2ui` package. This allows AI coding agents and backend streams to dynamically generate and control complex layouts of maps, charts, forms, and tools using standard JSON streams.

### Custom Catalog

We publish two auto-generated catalogs containing Zod schemas for all EOxElements:

1. **EOxElements Custom Catalog**
   This is our custom catalog containing strictly EOxElements components.
   - **Catalog ID/URL**: `https://eox-a.github.io/EOxElements/a2ui/0_9/eox_catalog.json`

2. **Combined Catalog** (Additional Helper)
   This is an additional helper catalog that combines standard `@a2ui/lit`'s `basicCatalog` with our custom EOxElements catalog. It is useful for applications that need both in one place.
   - **Catalog ID/URL**: `https://eox-a.github.io/EOxElements/a2ui/0_9/combined_catalog.json`

### Mounting with `<eox-a2ui-wrapper>`

You can render this entire interactive workspace directly inside your webpage by using our wrapper element:

```html
<!-- Load elements and wrappers -->
<script type="module">
  import "@eox/elements-a2ui";
  import "@eox/elements/map";
  import "@eox/elements/drawtools";
  import "@eox/elements/layercontrol";
</script>

<!-- Render the stream -->
<eox-a2ui-wrapper id="workspace-renderer"></eox-a2ui-wrapper>

<script>
  const renderer = document.getElementById('workspace-renderer');
  renderer.stream = /* the JSON specification stream above */;
</script>
```

## MCP Apps Integration

In addition to host-rendered A2UI, EOxElements supports the [**MCP Apps** (`io.modelcontextprotocol/ui`)](https://github.com/modelcontextprotocol/ext-apps) standard via `@eox/elements-mcp-app`. This allows MCP servers to bundle `<eox-map>`, `<eox-chart>`, `<eox-layercontrol>`, or `<eox-a2ui-wrapper>` inside sandboxed `ui://` iframe views that render across compatible AI hosts (Claude, ChatGPT, VS Code, Goose, etc.).

### Using `<eox-mcp-app>` in a `ui://` View Bundle

```html
<script type="module">
  import "@eox/elements-mcp-app";
  import "@eox/map";
  import "@eox/layercontrol";
  import "@eox/chart";
</script>

<eox-mcp-app show-layercontrol forward-a2ui-actions></eox-mcp-app>
```

`<eox-mcp-app>` connects over the `@modelcontextprotocol/ext-apps` `postMessage` bridge, listens for `ui/notifications/tool-result` (`structuredContent`), reports container height via `ui/notifications/size-changed`, and automatically renders:

- **A2UI payloads** (`stream`, `messages`, `components`, or A2UI arrays) via `<eox-a2ui-wrapper>`.
- **Direct geospatial / chart payloads** (`layers`, `center`, `zoom`, `tile_url`, `bbox`, `geojson`, or `vega_lite_spec` / `spec`) via `<eox-map>` + `<eox-layercontrol>` or `<eox-chart>`.

### Functional Bridge & CSP Helper

For custom view layouts or server-side `_meta.ui.csp` configuration:

```js
import {
  connectMcpApp,
  onToolResult,
  sendMessage,
  callServerTool,
  buildEoxCspMeta,
} from "@eox/elements-mcp-app";

onToolResult((structuredContent) => {
  // Bind structuredContent to your custom EOxElements layout
});

// Server-side _meta.ui.csp helper (includes EOX basemaps, blob:, data:, plus your STAC/TiTiler origins)
const meta = buildEoxCspMeta(["https://api.explorer.eopf.copernicus.eu"]);
```

The `@eox/elements-mcp-server` package also exposes a `ui://eox-elements/preview` MCP App resource for interactive component story previews.
